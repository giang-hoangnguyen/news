Motlab giúp Claude Code làm clip từ ảnh và tài liệu của bạn

Motlab là công cụ mã nguồn mở biến mỗi cảnh video thành mã vẽ, để Claude Code tự dựng clip từ ảnh, logo, tài liệu bạn đưa rồi xuất MP4 từ 720p đến 4K, không cần mô hình tạo video; tác giả chủ yếu thử trên máy Windows. Đọc

  1. Cài Node.js 24, Chrome và ffmpeg, rồi chạy npm install -g @motlab/cli và npx @motlab/cli setup (mặc định cài skill cho Claude Code).
  2. Chạy motlab edit example để xem clip mẫu trong trình duyệt.
  3. Bỏ ảnh và slide vào một thư mục, nhờ Claude Code: "Làm clip 30 giây giới thiệu học phần Máy CNC từ thư mục này", xem lại rồi bấm Export.
